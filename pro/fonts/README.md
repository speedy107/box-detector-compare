# IBM Plex font assets

Self-hosted, unmodified Latin WOFF2 subsets for the Cube Lens Pro interface.
IBM Plex Sans supplies interface text; IBM Plex Mono supplies numerical measurements and telemetry.

## Sources

- `@fontsource/ibm-plex-sans` 5.3.0: https://registry.npmjs.org/@fontsource/ibm-plex-sans/-/ibm-plex-sans-5.3.0.tgz
- `@fontsource/ibm-plex-mono` 5.3.0: https://registry.npmjs.org/@fontsource/ibm-plex-mono/-/ibm-plex-mono-5.3.0.tgz

Versions and tarball SHA-512 integrity values were read from the npm registry metadata on 2026-10-19. Both archives were verified against that metadata before extracting the files. No package code was installed or executed.
